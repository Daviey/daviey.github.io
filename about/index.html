Dr. Dave Walker

Security leader. Built and led teams securing billions in assets across cloud, crypto, and enterprise infrastructure.

What This Blog Covers

Cloud security architecture on GCP. Cryptocurrency key custody and blockchain defence. Identity, access, and zero trust. AI/ML applied to threat detection. The hard calls that come with owning security outcomes at scale.

Track Record

Head of Engineering for Ubuntu Server and Cloud. Ubuntu Core Developer. Built the product that runs most of the cloud you use today.

Moved into security leadership for global financial institutions. Defined GCP security baselines adopted enterprise-wide. Built CSIRT programmes, led penetration testing and red team operations, drove vulnerability management across multi-cloud estates. Owned security governance under NIST 800-53, SOC 2, FedRAMP, and ISO27001.

Designed cryptocurrency key custody for production blockchain systems: HSM-backed signing, multi-signature approval workflows, full audit trails. Audited smart contracts for institutional token deployments using Slither and Mythril.

PhD in Information Security. Research on defensive controls for blockchain systems: kill switch mechanisms, ML-based threat detection achieving 98.2% detection rate for reentrancy attacks, BLS threshold signatures for protocol-level security.

Currently focused on GCP security architecture and AI/ML security operations.

"Your job is to own the outcome. All of it. Including the parts you can't control."

How I Think About Security

  • Security leaders own outcomes, not controls
  • Meetings are inputs. Judge yourself by what ships after them
  • Monitoring accuracy matters more than monitoring uptime
  • Build political capital and spend it when you need to say no
  • Ship security decisions, not security documents
  • Boring tools plus discipline beat fancy platforms every time
